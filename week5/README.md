# CS50P – Week 5: Unit Tests

This repository contains my solutions for **Week 5: Unit Tests** from Harvard's **CS50's Introduction to Programming with Python (CS50P)**.

## Files

- `bank.py` – Determines the amount owed based on a greeting.
- `test_bank.py` – Unit tests for `bank.py`.
- `twttr.py` – Removes vowels from input text.
- `test_twttr.py` – Unit tests for `twttr.py`.
- `fuel.py` – Converts fractions into percentages and displays a fuel gauge.
- `test_fuel.py` – Unit tests for `fuel.py`.
- `plates.py` – Validates vanity license plates.
- `test_plates.py` – Unit tests for `plates.py`.

- Unit Testing

- Writing Test Functions
- Test-Driven Development (TDD)
