- `re.search()`

## 📝 Problem Descriptions

### 🔹 numb3rs
Validates whether a string is a valid IPv4 address.

### 🔹 watch
Extracts a YouTube video ID from an HTML iframe and converts it into a shortened `youtu.be` URL.

### 🔹 working
Converts 12-hour time format into 24-hour time while validating the input.

### 🔹 um
Counts standalone occurrences of the word **"um"**, ignoring capitalization.

### 🔹 response
Validates email addresses using the `validator-collection` library.

## 🧪 Running the Programs

Run any program using:


Run all tests:


```bash

pytest test_um.py
pytest test_response.py
```
