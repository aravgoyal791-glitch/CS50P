## 📝 Problems

### 🍪 Cookie Jar
Implemented a cookie jar class that supports storing, depositing, withdrawing, and displaying cookies while enforcing capacity constraints.

### 🌱 Seasons
Calculated the number of minutes between a user's birth date and the current date, converting the result into words using Python libraries.

### 👕 CS50 Shirtificate
Generated a personalized CS50 shirt certificate in PDF format using Python.
